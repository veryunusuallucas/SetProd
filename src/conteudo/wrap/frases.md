# Frases do wrap

Este arquivo é a lista de verdade. O que estiver aqui é o que aparece na tela
no fim de cada diária — o app sorteia uma, sem repetir a do dia anterior.

Como mexer:

- Uma frase por linha, com ou sem o tracinho na frente.
- Linha em branco é ignorada.
- Linha começando com `>` é comentário: fica no arquivo e não vai para a tela.
- Os títulos com `#` decidem em que lista a frase entra. Só existem duas: a que
  diz **diária** e a que diz **filme**.
- Qualquer outro título (`### as engraçadas`, por exemplo) é só um subtítulo
  seu: as frases embaixo dele continuam na lista em que já estavam.
- O que estiver escrito antes do primeiro título — como este parágrafo — nunca
  vira frase.

> As frases abaixo são um ponto de partida. Apague, troque, escreva as suas.

## No fim de cada diária

- É isso. Bom wrap.
- Acabou o dia. Amanhã tem mais.
- Está no lata.
- Corta. Foi bom.
- Wrap. Vão com cuidado na estrada.
- Mais um dia que virou filme.
- Desprodução, pessoal. Obrigado.
- O dia acabou e ninguém se machucou. Isso também é resultado.
- Guarda tudo com carinho, amanhã abre de novo.
- Bom trabalho. Sério.

## No fim do filme

> Esta lista só toca uma vez por produção: no último dia de filmagem.

- É um filme.
- Acabou. Vocês fizeram um filme.
- Último wrap. Esse a gente lembra.
